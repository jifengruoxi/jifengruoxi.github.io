# 怎么样用 dsh：以写论文为应用聊聊

以写论文为例，聊聊怎么用 dsh 和电脑一起干活。

## 一、下载 dsh

打开 [https://dshdesktop.com/zh/](https://dshdesktop.com/zh/)，下载对应版本的 dsh。

## 二、配置 Token

需要充值一点点钱。打开 [DeepSeek 开放平台](https://platform.deepseek.com/usage)，登录后充值 5 元左右，然后新建一个 API Key。

![DeepSeek 开放平台充值并新建 API Key](deepseek-recharge.png)

## 三、把 API Key 填进 dsh

打开 dsh，复制并添加上你的 API Key（下图中「API 密钥」这里）。

![在 dsh 设置中填入 API 密钥](dsh-apikey.png)

## 四、配置工作区

学习一下工程管理的思想，新开一个文件夹，用来放文本、图标、工作文件。

分类管理、准确提出要求，是用 dsh 和电脑工作的基本素养。

![在 dsh 中配置工作区文件夹](dsh-workspace.png)

## 五、把要求和空白模板交给 dsh

把要求和空白的模板给 dsh，并打开创造模式（笑）。

![向 dsh 提交论文要求和空白模板](dsh-prompt.png)

![在 dsh 中打开创造模式](dsh-createmode.png)

## 六、等待并指导

等待十分钟，并给 AI 指导就可以了。
